# HADI for Android and iOS

Builds of the HADI phone app, made here from HADI's source on every change.

- **Android:** download the newest APK from [the latest release](../../releases/latest), or directly: [`HADI.apk`](../../releases/latest/download/HADI.apk). Open it on the phone to install.
- **iPhone:** each build goes to TestFlight.

The build recipe is [`.github/workflows/release.yml`](.github/workflows/release.yml).
